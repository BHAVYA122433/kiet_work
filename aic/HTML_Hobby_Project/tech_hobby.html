quick guide of setting up ubuntu alongside macos

  • prerequisites
    • USB Flash Drive (8GB+)
    • At least 30GB free disk space
    • Full system backup(recomended)
  • Installation Steps

    1. Partition the Hard Drive

      Use Disk Utility on macOS to create a free space partition for Ubuntu.

    2. Flash Ubuntu ISO to USB

      Download the latest Ubuntu ISO from the official ubuntu website and write it to the flash drive.

    3. Boot and Install

      Restart the Mac while holding the Option key, select the USB boot drive, and complete setup.
